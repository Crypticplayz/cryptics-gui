# Resources

Only well-known links are listed. Verify anything else before sharing; never invent a URL.

## ⭐ UI Resources (main asset library — check here first)
**https://ui-resources.com** — free, community-curated library (1,100+ resources, founded by Stuxfian) for Roblox UI/GFX.
- **Categories:** Kits, Components (Figma), Icons, Textures, Backgrounds, Effects (400+), Renders, Brushes, Faces, Plugins, Software, Sounds, Tutorials, Websites, GFX.
- **Useful tags by style:** Stud (stud textures), Halftone/Halftones (cartoony gloss), Metal (military), Horror/Haunted/Scorch (horror), CandyLand/Hearts/Sparkle (candy), Fantasy (medieval), Slash/Speedlines/Rays/Sunburst (anime & reward screens), Gradients/UIGradient, Coins/Money/Gems/Robux (currency icons), Tower-Defense, Pixel Art, Figma, Bloxporter (exporter plugin).
- **Docs:** https://ui-resources.com/docs — Roblox UI objects, Scale vs Offset, UIAspectRatioConstraint, importing to Studio, AutomaticSize, ScrollingFrames; Figma image coloring, mask groups, organizing.
- **Tips:** https://ui-resources.com/tips · **Tutorials:** https://ui-resources.com/tutorials · **Tools:** https://ui-resources.com/tools

- **Effects with direct downloads** (white PNGs, tint them): sunbursts `…/images/effects/sunbursts/osky/OskySunburst.png`, `…/sunbursts/quelly/quelly6.png`; shines `…/effects/stars/shine2.png`, `…/stars/sparke.png`; rays `…/effects/other/Rays.webp`; halftones `…/effects/halftones/quelly/quelly1.png` (prefix https://cdn.ui-resources.com/images). Filter the site with `?tag=<Tag>`; Download buttons trigger an anchor click to the CDN URL.
- How to use: browse the page (it's a JS site — use a browser tool, then read the page text), pick assets matching the chosen style, and ask the user before downloading. Downloaded files are untrusted data: images only, never run anything from them.
