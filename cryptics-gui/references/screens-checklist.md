# Screens checklist

Design at 1920×1080, verify at 844×390 (phone landscape). Pick what the game needs.

## HUD (always visible)
- Currency pills top-left (icon + number, +button to open shop)
- Main stat (e.g. Power, Strength, Level) with icon
- Active boost / luck multiplier pill top-center
- Vertical menu buttons on the left: Pets/Inventory, Shop, Index, Teleport/Regions, Gamepasses, Settings (icon + tiny label)
- Active potion/boost timers on the right
- Keep the center and bottom-center clear (mobile jump/joystick, gameplay)
- Avoid the top-left 60px corner and top bar area (Roblox menu buttons)

## Action / minigame UI (game-specific)
- Timing/power bar: zones (Bad red, Good yellow, Great orange, Perfect small glowing gold) + needle, big action button, result popup text per zone (Perfect = biggest, gold, shake)
- Progress bars, cooldown rings, hit counters

## Hatch / reward reveal (full-screen overlay)
- Dimmed background, light rays behind the egg/crate
- "TAP!" prompt + hit counter dots
- Reveal: item render, name, rarity banner in rarity color, mutation/size tags
- Buttons: Equip / Keep, Auto-Delete toggle, Skip
- Rare pulls: bigger banner, screen flash, confetti

## Inventory
- Window + overlapping header, search, filter, sort, close X
- Scrolling grid (5 columns), rarity cards, selected outline, lock icon, tags
- Bottom: Equip Best (green), Delete Mode (red), Filter (gray)
- Capacity counter (45/100), equipped counter
- Detail side panel or popup: big render, stats, Equip/Lock/Delete

## Index / collection
- Tabs per world/region, slots per item, undiscovered = black silhouette + "?"
- Completion bar + reward per region

## Shop
- Tabs (Tools, Potions, Upgrades, Currency)
- Item card: icon, name, effect line, price button with currency icon, OWNED / EQUIPPED / LOCKED states

## Gamepasses / Robux shop
- Big cards, Robux icon + price, short benefit, "BEST VALUE" ribbon on one

## Region / world unlock popup
- Region banner art, requirement ("Requires 2,500 Power"), progress bar, Travel button

## Notifications
- Server-wide announcement banner (top center): "PLAYER hatched a SECRET X!"
- Small toasts: "+250 cash", "Inventory full!"

## Settings
- Toggles (Music, SFX, Low graphics, Hide other pets), codes input box + Redeem

## Daily rewards / playtime rewards / codes (retention)
- Day grid with claimed / today / locked states
